# Warm Welcome Landing

Crie uma landing page moderna, elegante, acolhedora e responsiva para a cafeteria **Café Imigração**, localizada em Santa Bárbara d’Oeste – SP.

O objetivo principal da página é apresentar a cafeteria, despertar desejo pelos produtos, transmitir uma sensação de acolhimento e tradição e incentivar o visitante a entrar em contato pelo WhatsApp, visitar o estabelecimento e conhecer o Instagram.

## ESTILO VISUAL

Criar uma identidade visual sofisticada, aconchegante e artesanal.

Paleta sugerida:

* Marrom café escuro
* Marrom médio
* Bege / creme
* Branco quente
* Pequenos detalhes em dourado ou caramelo

Usar bastante espaço em branco, bordas arredondadas, sombras suaves e uma estética premium, mas sem parecer excessivamente luxuosa.

A página deve transmitir:

* Aconchego
* Tradição
* Qualidade
* Café artesanal
* Comida preparada com carinho
* Lugar para criar memórias

Usar tipografia elegante para títulos e uma fonte moderna e extremamente legível para textos.

Evitar aparência de template genérico.
